# 📊 Data Visualization Midterm Project

## Overview

This project focuses on analyzing and visualizing data using Python. Various visualization techniques have been implemented to explore patterns, trends, and relationships within datasets. The project demonstrates the practical application of data visualization concepts using industry-standard Python libraries.

---

## Objectives

- Perform exploratory data analysis (EDA)
- Understand data distributions and trends
- Compare variables using graphical representations
- Identify patterns and correlations within datasets
- Present insights through effective visualizations

---

## Datasets Used

### Student Performance Dataset
Analysis of student scores and performance metrics to understand score distribution and demographic differences.

### Car Specifications Dataset
Analysis of automobile specifications including engine size, horsepower, and pricing to identify relationships between vehicle features and market value.

---

## Visualizations Implemented

### Student Performance Analysis

- Histogram
- Histogram with KDE
- Box Plot
- Distribution Plot
- Comparative Analysis

### Car Specifications Analysis

- Scatter Plot
- Correlation Analysis
- Price vs Engine Size Visualization
- Feature Relationship Analysis

## Key Findings

### Student Performance

- Student scores follow a near-normal distribution.
- Performance differences can be observed across demographic categories.
- Boxplots help identify score spread and potential outliers.

### Car Specifications

- Engine size shows a positive relationship with vehicle price.
- Higher horsepower generally contributes to increased pricing.
- Scatter plots reveal trends and variability among different car models.

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Data-Visualization-Midterm-Project.git
```

Navigate to the project folder:

```bash
cd Data-Visualization-Midterm-Project
```

Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```text
DV_Midterm.ipynb
```

and run all cells.
